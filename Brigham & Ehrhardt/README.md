Teks ekstraksi mencakup penanda seluruh 1.221 halaman PDF dan dibagi menjadi 34 bagian: bagian awal, 26 bab, empat lampiran, glosarium, serta dua bagian indeks/penutup. Format Markdown dapat dibaca langsung di GitHub atau diimpor ke GitBook. Ini belum merupakan situs GitBook/Jekyll yang diterbitkan.

Teks sumber dipertahankan dalam blok per halaman agar simbol yang rusak tidak diam-diam diganti dengan interpretasi baru. Tabel, grafik, gambar, dan persamaan belum seluruhnya direkonstruksi. Panduan belajar terpisah memberikan sintesis awal dan rumus standar dengan contoh baru.

**Cakupan arsip teks sudah lengkap menurut penanda halaman. Register rumus dan pembahasan soal terpilih tersedia; verifikasi manual seluruh rumus dan soal buku belum selesai. PDF asli sudah disertakan.** Lihat STATUS.md untuk rincian. Konfigurasi `.gitbook.yaml` di root menyiapkan struktur impor; situs GitBook belum diterbitkan.

Repository ini privat. Hak cipta buku tetap pada penulis/penerbit; arsip ini tidak memberikan lisensi distribusi ulang.
